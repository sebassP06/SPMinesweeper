# SPMinesweeper
https://spminesweeper.sp06dp07.workers.dev/

A clone of the original minesweeper in the browser with a leaderboard. Frontend was created with vanilla JS, HTML, and CSS and deployed on Cloudflare Workers. Backend was created with FastAPI/Python and deployed on render.com.

My intent with this project was to learn fullstack development and the CI/CD cycle.

If the leaderboard takes long a time to load that means the backend is being redeployed and will take approximately 50 seconds because I am on the free tier.
